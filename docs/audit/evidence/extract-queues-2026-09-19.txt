# this template's own source files write extensioned relative imports
# (consistent with invariant T5), so a project scaffolded fresh today needs
# either "module": "commonjs" (as done here) or every relative import
# rewritten with explicit ".js" extensions before ANY of this template's
# modules will compile in it — independent of which module is being lifted.
